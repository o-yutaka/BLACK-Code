# BLACK Sentinel atlas map

The V2 atlas is **1536 × 2288**, arranged as **8 columns × 11 rows**.
Each frame is **192 × 208** pixels.

| Row | Codex state | Visual language |
|---:|---|---|
| 0 | `idle` | Core breathing, tail sway, visor blink |
| 1 | `running-right` | Forward lean, alternating limbs, cyan speed lines |
| 2 | `running-left` | Mirrored traversal animation |
| 3 | `waving` | Raised arm, signal sparks, friendly acknowledgement |
| 4 | `jumping` | Clean vertical arc with tucked legs |
| 5 | `failed` | Red core, lowered posture, fragmented error pixels |
| 6 | `waiting` | Orbiting hourglass glyph for user input / approval |
| 7 | `running` | Holographic console and typing motion |
| 8 | `review` | Violet inspection lens and scan marks |
| 9 | look directions 000°–157.5° | Eight clockwise head/visor directions |
| 10 | look directions 180°–337.5° | Eight remaining clockwise directions |

Design rule: status must remain readable at small size without relying on text.
